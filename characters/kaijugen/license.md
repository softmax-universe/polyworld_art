# Kaijugen study provenance

Creator: Softmax / Polyworld contributors, with Codex authoring assistance.
Title: Kaijugen anatomical parts study.
Created: 2026-09-24.

The Blender meshes, materials, studio scenes and renders were authored
procedurally by `source/scripts/build_parts.py`. They use hand-shaped
cross sections and facial eye loops. No third-party meshes, textures,
HDRIs or font files are imported or packed.

The visual input was the user's six-panel anatomical wireframe reference,
identified in `source/provenance.json`. It guided proportions, color areas,
part separation and edge-flow direction. The reference image is not included
or relicensed by this repository. This study does not reproduce its exact
polygons. Previous Nim-generated character meshes were not imported.

Original project artwork in this directory follows the repository's
CC0-1.0 dedication in `../../LICENSE`. Authoring code follows the MIT
license in `../../LICENSE-CODE`.
